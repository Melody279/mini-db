# 协议 v0（引擎 ↔ 网关）

> 状态：M0 冻结。手机 App 不直连引擎，中间隔一层 HTTP 网关；网关负责 JSON↔TSV 与登录态。
> 请求一行一条，字段用 **`\t`** 分隔（SQL 里含空格，所以不用空格分隔）。编码 UTF-8。

## 1. 帧格式

```
请求：  <CMD> [\t<ARG>]...\n
响应：  OK <n_rows>\n[表头行\n][数据行...]\nEND\n
错误：  ERR <code> <reason>\nEND\n
```

- 写操作返回 `OK 0\nEND\n`；查询返回 `OK <n>` + 一行表头 + n 行数据，行内字段也用 `\t`。
- 空行视为心跳，回 `OK 0`。
- 客户端在收到 `END` 之前不得发送下一条请求（单连接串行）。

## 2. 命令

| CMD | 参数 | 说明 | 状态 |
|---|---|---|---|
| `PING` | — | 保活 | M0 已实现 |
| `HELLO` | — | 版本握手 | M0 已实现 |
| `QUIT` | — | 关闭连接 | M0 已实现 |
| `EXEC` | SQL 文本 | 执行受限 SQL（见 §3） | W1 |
| `EXPLAIN` | SQL 文本 | 打印算子树（题4） | W2 |
| `BIZ` | 命令名 + 参数 | 12 个业务命令（见 §4） | W3 |

## 3. 受限 SQL 子集（W1 只做这些，别贪）

```
SELECT col[, col ...] FROM t [WHERE pred (AND pred)*] [ORDER BY col [DESC]] [LIMIT n]
SELECT COUNT(*) | SUM(col) FROM t [WHERE pred] [GROUP BY col]
SELECT cols FROM t JOIN t2 ON t.c = t2.c [WHERE pred]
INSERT INTO t VALUES (v[, v ...])
UPDATE t SET col = v [WHERE pred]
DELETE FROM t [WHERE pred]
EXPLAIN <上述任意语句>
```

`pred := col OP value`，`OP ∈ {=, <>, <, <=, >, >=}`，`value` 为整数或单引号字符串。
**不支持**：子查询、OR、IN、多表 JOIN（>2）、窗口函数、事务内多语句。超出即报 400。

## 4. 业务命令（`BIZ` 的 12 个命令）

| 命令 | 参数（`\t` 分隔） | 返回 |
|---|---|---|
| `LOGIN` | role, login_name, pwd | uid, role |
| `ORDER_CREATE` | pid, from_addr, to_addr, car_type | oid, state |
| `DISPATCH` | oid | did（无候选返回 0） |
| `ORDER_ACCEPT` | oid, did | 新 state |
| `ORDER_REJECT` | oid, did, reason | 新 state |
| `TRIP_ARRIVE` | oid | 新 state |
| `TRIP_START` | oid | 新 state |
| `TRIP_FINISH` | oid, distance_m, duration_s | 新 state, fare |
| `PRICE_CALC` | car_type, distance_m, duration_s | fare |
| `DRIVER_TOGGLE` | did, online | 新 online |
| `ADMIN_QUERY` | kind, 参数... | 结果集 |
| `STAT_AREA` | lon_center, lat_center, radius_m | 待接单数/完成数/取消数 |

规则：**所有写状态的命令内部必须过 `CanTransit`**（`include/db/biz.h`），非法跳转返回 `ERR 403 invalid-state-transition`。

## 5. 角色权限矩阵

| 能力 | 管理员 | 司机 | 乘客 |
|---|---|---|---|
| 登录 | ✓ | ✓ | ✓ |
| 下单 / 取消自己的单 | — | — | ✓ |
| 接单 / 拒单 / 行程操作 | — | ✓ | — |
| 维护司机车辆档案、计价规则 | ✓ | — | — |
| 查看全量订单、异常订单 | ✓ | — | — |
| 查看自己订单 | — | ✓（自己接的） | ✓（自己下的） |

双层校验：网关按 token 判角色（粗筛），引擎在 `BIZ` 内再按 `ref_id` 校验归属（细筛）。**不允许只靠前端隐藏按钮**。

## 6. 错误码

| code | 含义 | 典型触发 |
|---|---|---|
| 400 | 语法/参数错误 | SQL 超出受限子集、参数个数不对 |
| 401 | 未登录/角色不符 | token 缺失 |
| 403 | 状态非法/无权限 | 已完成订单再 finish、司机看别人单 |
| 404 | 对象不存在 | oid 不存在 |
| 409 | 冲突（重复/并发） | 两司机抢同一单、手机号重复 |
| 501 | 功能未实现 | M0 阶段的 EXEC/BIZ |
| 500 | 内部错误 | IO 失败、断言 |

## 8. 网关映射（HTTP → BIZ）

| REST | 引擎命令 | 备注 |
|---|---|---|
| `POST /api/login` | `BIZ LOGIN` | 网关签发 token（内存字典即可，课程作业不做 JWT） |
| `POST /api/order` | `BIZ ORDER_CREATE` | |
| `POST /api/order/{id}/dispatch` | `BIZ DISPATCH` | 演示时可手动触发派单 |
| `POST /api/driver/accept` | `BIZ ORDER_ACCEPT` | |
| `GET /api/order/{id}/status` | `EXEC SELECT state,created_at,accepted_at,arrived_at,started_at,finished_at FROM orders WHERE oid=?` | App 3 s 轮询 |
| `POST /api/trip/finish` | `BIZ TRIP_FINISH` | 返回计价明细 |
| `POST /api/driver/toggle` | `BIZ DRIVER_TOGGLE` | |
| `GET /api/admin/...` | `BIZ ADMIN_QUERY` | 档案、规则、异常单 |

网关是本工程里**唯一允许重度用 AI 生成**的部分（AI 使用声明会记录）；它的职责边界写死：不含业务规则、不含状态机、不做 SQL 拼接以外的加工。
